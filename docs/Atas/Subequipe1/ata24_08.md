## 3. Discussões

### Artefato Generalista (Rich Picture ou Mapa Mental)
- Cada integrante produzirá o seu próprio artefato generalista, escolhendo individualmente entre Rich Picture e Mapa Mental.
- No documento compartilhado, cada um deve escrever uma introdução explicando o que é o artefato escolhido e, principalmente, justificar a escolha.
- Ficou esclarecido que o Mapa Mental pode representar o sistema como um todo, não sendo necessário restringi-lo a um fluxo específico.

### SIG / NFR Framework
- Reconhecido pelo grupo como a parte mais difícil da entrega.
- Cada integrante ficará responsável por um galho da árvore, ou seja, por um requisito não funcional.
- Caso a ferramenta disponibilizada no site da professora funcione online, a edição será feita de forma colaborativa e simultânea; caso contrário, cada um desenvolve o seu galho separadamente e o grupo marca uma reunião para consolidar tudo.

### Engenharia Reversa
- As perguntas do material da professora serão divididas entre os integrantes.
- Na prática, o trabalho consiste em listar o que está apresentado na tela e registrar por escrito cada elemento observado.
- A partir desse levantamento, o grupo identificará os fluxos, as regras de negócio e os requisitos do sistema.

### BPMN
- O BPMN partirá de um dos fluxos identificados pela engenharia reversa, portanto depende da conclusão dela.
- Definiu-se o uso do Miro por permitir edição simultânea entre os integrantes.
- O Bizagi foi descartado devido aos problemas de instalação enfrentados pelo grupo no semestre passado.
- Cada integrante ficará responsável por uma parte do diagrama.

### IA Generativa
- O relato sobre o uso de IA Generativa é individual: cada integrante escreve o seu próprio ponto de vista.
- Reforçou-se que esse item não é opcional.

### Organização da Documentação
- O link do GitHub Pages já existe, mas está desorganizado; será estruturado por subgrupos.
- Será criado um documento compartilhado (Google Docs) para que o grupo responda às perguntas da engenharia reversa.
